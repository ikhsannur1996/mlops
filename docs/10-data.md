# 10 - Data

The repository ships with a realistic, reproducible dataset instead of a toy
balanced one:

```text
data/train.csv    8000 rows   the split the model is trained on
data/test.csv     2000 rows   held-out split used for evaluation and simulation
```

Both splits are committed so a fresh clone can `python src/train.py` straight
away, and both are regenerated by the same generator, so they always describe
the same population.

## Why a generator instead of a random CSV

A credit portfolio is not 50/50. Real consumer-lending books default on a few
percent of exposures, and income is log-normal rather than uniform. `src/
generate_data.py` builds a population that looks like that:

- **Income** is drawn from a log-normal distribution — many modest incomes and a
  thin tail of high earners.
- **Loan sizing is affordability-based**: `loan_amount` is derived from income
  and tenure, so debt service is a plausible share of income instead of an
  independent random number.
- **Risk is latent**: each applicant gets a score built from income, debt
  service, age and tenure, and the threshold that score is calibrated against so
  that the realised default rate matches `TARGET_DEFAULT_RATE` (default `0.12`).
- **The two splits are disjoint**: applicants are generated once and then split,
  so no row appears in both files, and duplicates are dropped inside each split.

The result is a dataset on which a model has to actually rank risk — which is
why `src/train.py` sweeps decision thresholds instead of assuming `0.5`.

## Regenerate the data

```bash
make data
# or
python src/generate_data.py
```

Everything is configurable through the environment:

| Variable | Default | Meaning |
| --- | --- | --- |
| `DATA_DIR` | `data` | where the CSVs are written |
| `N_TRAIN` | `8000` | rows in `train.csv` |
| `N_TEST` | `2000` | rows in `test.csv` |
| `RANDOM_SEED` | `42` | makes the split and values reproducible |
| `TARGET_DEFAULT_RATE` | `0.12` | default rate the risk model is calibrated to |

For example, a bigger book with a nastier cycle:

```bash
N_TRAIN=20000 N_TEST=5000 TARGET_DEFAULT_RATE=0.15 python src/generate_data.py
```

The same seed always produces byte-identical files, so regeneration is safe to
run in CI or on a teammate's machine.

## Schema

`train.csv` and `test.csv` share exactly these columns, in this order:

```text
age, income, loan_amount, tenure, default
```

`default` is the binary target (`0` = repaid, `1` = defaulted). All four
features are numeric with no missing values.

## Data quality gates

`tests/test_data_quality.py` enforces the contract on every CI run:

| Gate | Bound |
| --- | --- |
| Columns | `age, income, loan_amount, tenure, default` |
| Rows | ≥ 1000 train, ≥ 250 test |
| Default rate | between 3% and 30% in **both** splits |
| Duplicates | none inside either split |
| Overlap | no applicant in both splits |
| Train vs test | default rates within 3pp, feature medians within 25% |
| Business ranges | age 18–100, `income` > 0, `loan_amount` > 0, tenure 1–120 |
| Shape | income and loan amount are right-skewed (mean > median) |

`tests/test_generate_data.py` covers the generator itself: reproducibility by
seed, split sizes surviving deduplication, disjoint splits, calibration of the
bad rate to the requested value, and the direction of the risk drivers (higher
debt service → more defaults, higher income → fewer).

## Where the data is used

| Consumer | Variable | Default |
| --- | --- | --- |
| `src/train.py` | `TRAIN_DATA` / `TEST_DATA` | `data/train.csv` / `data/test.csv` |
| `src/evaluate.py` | `TEST_DATA` | `data/test.csv` |
| `src/simulate.py` | `TEST_DATA` | `data/test.csv` |

Training fits on `train.csv` and reports holdout metrics on `test.csv`;
evaluation scores the *registered* model on the same `test.csv`, so training and
evaluation metrics agree by construction. Monitoring never reads these files —
it compares the production prediction log against `train.csv` as the reference
population.

See `docs/11-api-simulation.md` for how `test.csv` also feeds simulated
production traffic.
